# Earlier Fixed-Calendar Prototype

This directory preserves the earlier JCR/CRP/RCRP artifact and its recorded experiments. It studies reduction over a fixed, feasible refresh and delivery calendar. It is retained for provenance and is not the current PG-VCR experiment package.

The original commands remain available from this directory. Paths in some frozen workers record their historical workspace; use `reproduce.py`, which prepares a copied worker and replaces those paths for the selected output.
